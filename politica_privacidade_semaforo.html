Política de Privacidade — Semáforo de Avisos

Última atualização: 13 de setembro de 2026

Esta Política de Privacidade descreve como o aplicativo Semáforo de Avisos trata informações durante sua utilização.

1. Sobre o aplicativo

O Semáforo de Avisos é uma ferramenta de comunicação que permite ao usuário indicar, por meio de sinais visuais, mensagens textuais e reprodução de áudio, diferentes estados ou necessidades de comunicação.

2. Coleta de dados pessoais

O aplicativo não solicita cadastro, não possui conta de usuário e não coleta diretamente informações pessoais como nome, endereço, número de telefone, contatos, localização, fotos, vídeos ou documentos.

3. Armazenamento e compartilhamento

O aplicativo não mantém uma base própria de dados pessoais e não vende, aluga ou compartilha dados pessoais do usuário com terceiros para fins publicitários.

4. Reprodução de voz

Quando o usuário solicita a reprodução de uma mensagem, o aplicativo utiliza o mecanismo de conversão de texto em fala disponível no dispositivo Android. O aplicativo não mantém um histórico próprio das mensagens reproduzidas.

5. Conexão com a internet e fontes de texto

A versão atual do aplicativo utiliza recursos de fonte disponibilizados pelo Google Fonts. Para carregar esses recursos, o dispositivo pode realizar uma conexão com servidores externos. Essa conexão pode envolver informações técnicas normalmente necessárias para uma comunicação na internet, como endereço IP e informações do dispositivo/navegador.

O Semáforo de Avisos não utiliza essa conexão para criar um perfil do usuário, realizar publicidade ou coletar o conteúdo das mensagens exibidas no aplicativo.

6. Publicidade

O aplicativo não exibe anúncios e não utiliza redes de publicidade.

7. Segurança

O aplicativo foi desenvolvido para minimizar o tratamento de informações pessoais. Como não mantém uma conta ou banco de dados próprio de usuários, não há armazenamento próprio de dados pessoais para proteger por meio de autenticação.

8. Crianças e público-alvo

O aplicativo não exige o fornecimento de informações pessoais para ser utilizado. A classificação e o público-alvo definidos na Google Play são informados separadamente no cadastro do aplicativo e não alteram as práticas de tratamento de dados descritas nesta política.

9. Alterações nesta política

Esta política poderá ser atualizada caso as funcionalidades ou as práticas de tratamento de dados do aplicativo sejam modificadas. A versão atualizada será publicada nesta mesma página, com a respectiva data de atualização.

10. Contato

Para dúvidas ou solicitações relacionadas a esta Política de Privacidade, entre em contato por meio do perfil do projeto no GitHub: github.com/jeffersonjcd.
